md_content = """# 🎵 오노추 (오늘의 노래 추천)

## 프로젝트 소개
'오노추(Music Recommend)'는 매일 자신만의 음악을 기록하고 추천하며, 친구들 및 그룹과 함께 음악 취향을 공유할 수 있는 소셜 음악 기록 웹 플랫폼입니다.

## 주요 기능
- **회원 관리 & 이메일 인증:** PHPMailer를 활용한 이메일 인증 회원가입, 로그인 및 마이페이지 프로필(상태 메시지, 디데이 설정) 관리 기능
- **오늘의 노래 기록:** 유튜브 URL을 입력하여 오늘의 노래(썸네일, 제목 등)를 등록하고 '오늘의 한마디'를 남기는 기능
- **음악 캘린더:** 날짜별로 자신이 등록한 노래를 달력 형태로 한눈에 모아보는 기능
- **소셜 및 그룹 기능:** - 친구 요청 및 수락을 통한 친구 관리
  - 그룹(클럽) 생성 및 멤버 관리 기능을 통해 특정 소속 내에서 노래 공유
- **소통 기능:** 공유된 노래에 댓글을 달아 사용자 간 소통(댓글 CRUD 기능)

## 기술 스택
- **Frontend:** HTML5, CSS3, Vanilla JavaScript
- **Backend:** PHP
- **Database:** MySQL
- **Library/API:** PHPMailer (이메일 인증 로직)

## 데이터베이스 스키마 (ERD 요약)
프로젝트의 핵심 데이터를 관리하는 주요 테이블 구조입니다.

- **`users`**: 사용자 기본 정보, 프로필(bio, dday), 현재 설정된 노래 및 프라이버시 설정
- **`songs`**: 사용자가 등록한 노래 정보 (유튜브 URL, 제목, 썸네일 경로, 등록 날짜/시간)
- **`friends`**: 사용자 간의 친구 맺기 상태 (pending, accepted)
- **`club_groups` & `group_members`**: 그룹 채널 정보 및 그룹에 가입된 사용자의 권한(role) 관리
- **`song_comments`**: 등록된 노래에 대한 유저들의 댓글 내용 기록
- **`email_verifications`**: 회원가입 시 이메일 인증 코드 발송 내역 및 인증 유효 상태 관리
